# Launcher OS

Un launcher Android inspirado en el diseño de iOS y Liquid Glass.

## Características del proyecto

- Pantalla de bloqueo con fotografías personalizadas.
- Reloj con efecto de profundidad, parcialmente detrás del sujeto de la fotografía.
- Pantalla principal con iconos y widgets.
- Centro de control con efecto cristal.
- Panel de notificaciones.
- Buscador de aplicaciones.
- Dock personalizable.

## Objetivo

Crear una experiencia visual elegante, moderna y funcional para Android 14.
